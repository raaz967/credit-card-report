## Featured Project

### 💳 Credit Card Transaction & Customer Analytics Dashboard

**Tools:** Microsoft Power BI, PostgreSQL

An interactive, two-page dashboard for exploring credit card transaction performance, financial metrics, and customer segments.

**Key Features**
- Revenue, transaction amount, and interest earned KPIs
- Quarterly revenue and transaction trend analysis
- Revenue breakdown by expenditure type and card category
- Payment-mode and card-type comparisons
- Customer segmentation by occupation, education, age, and income
- Weekly revenue trends and state-level comparisons

**Project Objective**

To organize transaction and customer data into interactive visualizations that support financial performance analysis and customer segmentation.
